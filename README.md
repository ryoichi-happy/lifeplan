# 人生設計

今から30歳までの「いつ何をするか（年表）」と「そのときお金は足りるか（資産の見通し）」を1画面で確認する、自分専用のスマホ向けWebアプリです。

- サーバーを使わず、ブラウザだけで動きます（素の HTML / CSS / JavaScript）
- 入力したデータは、使っている端末のブラウザの中にだけ保存されます。このリポジトリやサーバーには送られません
- ホーム画面に追加すると、アプリのように使えます（PWA）
- データはファイルに書き出して（エクスポート）、別の端末で読み込めます（インポート）

仕様は [SPEC.md](SPEC.md) にまとめています。

## 手元で動かす

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。テストは http://localhost:8000/test.html で実行できます。
